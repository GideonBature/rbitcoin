Changed

- **Library tests compile against the normal rlib.** Each library package has one `tests/suite` target (`[lib] test = false`), so `cargo test` no longer rebuilds the crate under `--cfg test`. `test-hooks` is gone. Hooks a test arms stay `cfg(debug_assertions)`. A debug node still uses the 8 s outbound connect timeout and still aborts when an io_uring drain leaves SQEs. Initial block download is `rbitcoin-ibd`, and RPC, Electrum, Esplora, and SV2 do not depend on it. `rbitcoin-test`'s default scenarios are one `suite` binary; `overlay` stays feature-gated. `NODE_COMPACT_FILTERS` is advertised per peer hub, so one process can run more than one node.
- **Production line-coverage floor is 89%.** Suite tests link the normal rlib, so `#[cfg(test)]` lines are no longer in the LCOV denominator. The gate is still unrounded `LH*100 >= LF*89`.
